\# SkillBridge — Capstone Specification



\## Capstone Option



\*\*FE3 — Internal Tool Builder\*\*



\## Target User



SkillBridge is designed for \*\*university students and early-career developers\*\* who are looking for internships and want help with their career preparation.



\## Core Flow



1\. The user opens SkillBridge and explores available internships and jobs.

2\. The user can browse internship opportunities and company information.

3\. The user can create and manage their profile.

4\. The user can use the AI Assistant for internship recommendations, resume improvement, interview preparation, and career guidance.

5\. The user can use the contact section to get in touch or submit an inquiry.



\## Main Screens



\* \*\*Home\*\* — Introduction to SkillBridge and its main features.

\* \*\*About\*\* — Information about the platform.

\* \*\*Jobs\*\* — Internship and job opportunities.

\* \*\*Internship\*\* — Internship-focused opportunities and information.

\* \*\*Companies\*\* — Company information and opportunities.

\* \*\*Contact\*\* — Contact form for user inquiries.

\* \*\*AI Assistant\*\* — AI-powered career assistance available to users.



\## Data Sources



The application uses structured application data for internships, jobs, companies, and user profile information. The AI Assistant uses an AI model through the AI SDK to generate career-related responses based on the user's questions and provided information.



\## AI Feature



The main AI feature is the \*\*SkillBridge AI Assistant\*\*.



It helps students with:



\* Finding suitable internship opportunities

\* Improving resumes

\* Preparing for interviews

\* Exploring career paths

\* Providing general career guidance



The AI Assistant is integrated directly into the SkillBridge experience so users can access career assistance without leaving the application.



\## Technology Stack



SkillBridge is built using \*\*Next.js with the App Router, TypeScript, and Tailwind CSS\*\*. This stack was chosen because it provides a modern React-based architecture, type safety, reusable components, and efficient responsive UI development.



\## Out of Scope



The following features are intentionally outside the scope of this capstone:



\* Full production-scale job-board integration

\* Real-time messaging between students and companies

\* Automated job application submission

\* Payment processing

\* Complex employer recruitment management

\* Advanced analytics and reporting

\* Building a custom AI model from scratch

\* A complete enterprise authentication and authorization system



\## Success Criteria



The project will be considered successful when a student can navigate SkillBridge, explore internship opportunities, access career-related information, and interact with the AI Assistant for useful career guidance through a clear and responsive interface.
